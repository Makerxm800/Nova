About

Nova Search

Version 2.0.0 · a local-first universal search for Windows, macOS and Linux.

  • Search — tiered fuzzy matching across names, folders, formats and tags, with a natural-language layer.
  • Preview — images, video, audio, PDF, text, code, spreadsheets, fonts, archives and design files.
  • Privacy — no server, no account, no telemetry. Metadata is stored in this profile only.
